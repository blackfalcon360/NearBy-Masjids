# Nearby Mosques | المساجد القريبة 🕌

Shows mosques near your location (OpenStreetMap data), nearest first.
Refresh location, Arabic / English (with RTL), tap a mosque to open it in your maps app.

Brought to you By: Black Falcon 🦅

## Build
Push to GitHub -> Actions -> "Build APK" -> download `NearbyMosques-APK`.
Local: `gradle assembleDebug` (JDK 17, Gradle 8.7+). Needs internet at runtime.
